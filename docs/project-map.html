Mario PC

Карта текущего исходного пакета. Все разделы работают локально без интернета.

  • Mario PC: запуск и сборка
    • → Игрок скачивает готовый ZIP из Releases
      Распаковать → MarioPC.exe + SDL3.dll → игровой экран и меню.
    • → Сборка Windows
      CMake соединяет frontend, ядро и зависимости.
      • → Окно и игровой цикл → клавиатура/геймпад/экран → физика и уровни
      • → Рендер получает тайлы и состояние → фон + персонаж + HUD
      • → Меню приостанавливает симуляцию → слот сохранения сохраняет память, картинку и фазу анимации
      • → 19 C++ проверок создают временные fixtures и результаты в build
    • → Графические оригиналы → генераторы → встроенные данные
      Существующие заголовки включены; для обычной пересборки обработка графики не нужна.
    • → Документы: состав, свежая проверка, история изменений, лицензии

Клавиатура/геймпад → нативная симуляция → визуальные слои → SDL3. Меню останавливает симуляцию; сохранение и загрузка переносят её состояние.
