# Исходники «Искры»

- `src/iskra_presentation.cpp` и `src/iskra_world.cpp` рисуют уровни, освещение и сюжетные заставки. `src/iskra_actors.cpp` отвечает за анимацию.
- `src/mario_main.cpp` соединяет игровой цикл, ввод, экран, звук и сохранения. Нативное ядро находится в `source/SMB-Vanilla`.
- `assets/iskra` содержит иллюстрации окружения, исходники декора и иконку. Происхождение малых спрайтов описано в [манифесте](../assets/iskra/atlas/manifest.json).
- `generated` содержит готовые заголовки графики, игровых данных и шрифта. `tools` содержит скрипты для повторной подготовки ресурсов.
- `dependencies` содержит библиотеки и шрифт для автономной сборки. Уведомления об авторстве находятся в [licenses](../licenses/README.md).
- `tests` содержит C++ проверки CTest и сценарии для исполняемого файла. [Отчёт](RELEASE_CHECKS.json) включает запуск 32 уровней и проверку совместимости сохранений.
- [Происхождение нативного порта](PORT_NOTES.md) описывает предшествующую версию Mario PC.
