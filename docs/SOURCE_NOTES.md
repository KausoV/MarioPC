# Состав исходников

В этот компактный пакет входят все исходники C/C++, встроенные данные и заголовки, зависимости для сборки Windows x64, 19 наборов C++ CTest и исходные графические материалы с инструментами обработки. Это соответствует текущему проверенному executable от 14 октября 2026 года; публикация подготовлена 23 ноября 2026 года.

Большие исторические скриншоты, дампы RAM, диагностические сохранения и старые frontend regression fixtures исключены. CMake/CTest их не требует: C++ проверки создают свои временные состояния в build. Поэтому отдельные исторические Python/PowerShell frontend-проверки, зависящие от этих архивов, также не включены.

Папки src, source, generated, assets и исходники 19 C++ проверок скопированы без изменения поведения. В копиях шести tools-генераторов личные пути первого импорта заменены путями к уже включённым проектным оригиналам; FFmpeg ищется через PATH или передаётся через параметр. Заранее подготовленные заголовки позволяют собрать игру без запуска генераторов.

- src/mario_main.cpp — окно, игровой цикл, интеграция рендера, звука, управления и сохранения.
- src/*_art.* и src/world_* — визуальное представление персонажа, окружения и предметов.
- source/SMB-Vanilla — нативная логика и звук; оригинальные уведомления сохранены.
- generated — встроенные данные, PNG/атласы и шрифт.
- assets — предоставленные оригиналы и подготовленные изображения.
- dependencies — включённые SDK, ImGui и шрифт.
- tools — обработка исходных материалов.
- tests/*.cpp — автономные проверки, включённые CMake.

Это сведения о прежнем испытании, не заявление о новом полном прохождении всех уровней. Свежий переносимый запуск описан в RELEASE_CHECKS.json.
